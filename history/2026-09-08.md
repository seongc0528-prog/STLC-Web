   - 이관 중 발견/수정한 버그: Storage 업로드 시 contentType 미지정 → 전부 `text/plain`으로 서빙되던 문제(`fix-storage-content-types.mjs`), Cloudflare가 **Range 요청을 별도 캐시**해서 일부 파일이 여전히 깨지던 문제(`rekey-poisoned-cache-files.mjs`로 전체 파일 새 경로 재발급하여 해결), 앨범 커버 매칭 버그(`fix-album-covers.mjs`로 재수정).
7. **Web Push(표준, Firebase 미사용) 구현**
   - 처음엔 FCM으로 설계했다가, "Firebase가 왜 또 필요하냐"는 질문을 계기로 **표준 Web Push(VAPID)로 완전 전환** — Google/Firebase 계정 불필요.
   - VAPID 키 쌍 직접 생성 (`npx web-push generate-vapid-keys`).
   - `supabase/functions/send-push` Edge Function: 관리자 권한 확인 → `web-push` npm 패키지로 저장된 모든 구독에 발송 → 무효 토큰 정리 → `push_logs` 기록.
   - 발견/수정한 버그들: 헤더가 로그인 상태를 아예 반영 안 하던 문제(`AuthButtons` 추가), `register()` 직후 바로 `subscribe()`해서 "no active Service Worker" 에러 나던 문제(`navigator.serviceWorker.ready`로 수정), 카카오톡 등 인앱 브라우저에서 알림 실패하던 문제 → **알림 버튼을 "설치(standalone) 상태에서만" 노출**하도록 설계 변경(`useIsStandalone`)으로 근본 해결.
