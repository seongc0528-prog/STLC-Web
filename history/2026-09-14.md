  - 행사 사진: 게이트 제거. 앨범 올리기 폼은 로그인했을 때만 렌더.
  - 공지사항: 게이트 제거.
  - 선교 소식: 게이트 추가.

## 4. 설치 앱에서 외부 링크 — 검토 결과

사용자 질문: "외부 링크를 넣었을 때 설치 앱에서 눌러도 괜찮은가?"

| 상황 | 사이트 안 링크 | 외부 링크 |
|---|---|---|
| 웹 브라우저 | 같은 탭 | 새 탭 |
| 설치 앱 · 안드로이드 | 앱 안에서 이동 | 크롬 창으로 열림, 닫으면 앱 복귀 |
| 설치 앱 · 아이폰 | 앱 안에서 이동 | 사파리로 열림, 앱은 보던 화면 유지 |
| 설치 앱 · PC | 앱 창에서 이동 | 기본 브라우저 탭 |

외부 주소를 설치 앱의 **같은 창**에서 열면 앱 화면 자체가 외부 사이트로 바뀌어(특히 iOS)
돌아오기 불편하다. 그래서:
- 링크 칸은 하나. `new URL(link, location.origin)`의 origin이 우리 사이트면 경로로 바꿔
  `<Link>`로 같은 창 이동 — `/support/news`로 적든 주소창 전체를 붙여넣든 같게 동작.
- 그 외는 `target="_blank" rel="noopener noreferrer"`.

| 항목 | 비로그인 | 로그인 |
|---|---|---|

| 댓글 (C3, 앨범+공지) | "댓글 N개 · 로그인하고 댓글 보기" | 읽기·쓰기·본인 삭제 (관리자는 전부 삭제) |
| 작성자 이름 (N2) | 안 보임 | 보임. 관리자 계정·author 없는 공지는 "관리자" |

### 마이그레이션 `0010_views_comments_authors.sql`
- `notice_comments` (photo_comments와 같은 모양, 내용 1~1000자 체크) + RLS: select 로그인, insert 본인, delete 본인/관리자.

- `comment_count(kind, target)` security definer, anon 실행 — 개수만.
- `author_names(ids uuid[])` security definer, **authenticated만** (public·anon revoke). role=admin이면 '관리자'.
