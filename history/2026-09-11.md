# STLC 홈페이지 프로젝트 — 2026-09-11 작업 기록

## 1. 이 세션의 목표

지금까지는 기능(인증, 푸시, Supabase 연동)만 붙이고 화면은 기본 Tailwind 회색 톤 그대로였다.
이번 세션은 **디자인**만 다뤘다. 메뉴 구조를 가져온 레퍼런스 사이트 <https://www.joych.org/>
(포항 기쁨의교회)에서 **비주얼 언어까지 추출해 디자인 시스템으로 이식**하는 것이 목표.

## 2. 레퍼런스 사이트 분석 방법

joych.org는 **Vite 기반 SPA**라 HTML에 본문이 없다. WebFetch로는 `<title>` 말고는
아무것도 안 나온다. 그래서 빌드 산출물을 직접 받아서 파싱했다.

```bash
curl -sL https://www.joych.org/ -o joych.html          # 에셋 경로 확인
curl -sL https://www.joych.org/assets/index-C1rvbl2e.css -o joych.css   # CSS 변수
curl -sL https://www.joych.org/assets/index-G0b9eNO9.js  -o joych.js    # 섹션 구성/색상
```

- **CSS** — 끝부분 `:root{}` 블록에 shadcn 스타일 토큰이 통째로 들어 있다.
- **JS** — 히어로 슬라이드 기본값, 퀵메뉴 배열, 하드코딩된 hex 색상 리터럴, `tracking-[...]`
  유틸리티 클래스를 그대로 뽑아낼 수 있다.

> 다음에 이 사이트를 다시 뜯어볼 일이 있으면 에셋 해시가 바뀌어 있을 테니
> `joych.html`을 먼저 받아 `/assets/index-*.css|js` 경로를 다시 확인해야 한다.

## 3. 구현 내용

### 디자인 토큰 — `src/app/globals.css`

Tailwind v4 `@theme` 블록으로 전부 토큰화했다.

- `--color-brand-50 ~ 900` (딥그린 스케일), `--color-cream-*`(웜 표면),
  `--color-ink / ink-soft / ink-muted / line`
- `--shadow-soft / card / brand`, `--radius-card`, `--animate-rise`
- `@layer components`에 `.eyebrow` `.display` `.rule` `.btn` `.btn-primary`
  `.btn-outline` `.btn-ghost-light` `.card` `.card-hover`
- `@utility container-page` — 공통 max-width + 좌우 패딩

> **브랜드 색을 바꾸려면 `--color-brand-*` 한 블록만 고치면 전체가 따라온다.**
> joych의 그린을 그대로 썼으므로, STLC 고유 색이 정해지면 여기만 교체하면 된다.

### 폰트 — `src/app/layout.tsx`

Geist / Geist Mono → **Noto Sans KR + Noto Serif KR + Playfair Display**.

`next/font/google`의 `subsets`에 `korean`이 없어서 한글이 빠질 위험이 있었는데,
빌드 산출물로 **실제로 포함되는지 검증**했다:

```bash
find .next/static -name "*.css" | xargs grep -l "AC00"
# → Noto Sans KR / Noto Serif KR 청크에서 unicode-range:U+AC00,U+ACE0,... 확인
ls .next/static/media | wc -l   # 253 (라틴만이면 5개 내외)
```

한글 글리프가 정상적으로 self-host된다. `themeColor`도 `#111827` → `#1B5E20`으로 변경.

### 홈 — `src/app/page.tsx`

링크 그리드 하나뿐이던 화면을 7개 섹션으로 재구성했다.

1. **히어로** — 딥그린 그라데이션, 스태거 진입 애니메이션(80/160/220/300ms),
   영문 eyebrow → 2행 세리프 헤드라인 → 설명 → 성구 출처 → CTA 2개
2. **퀵메뉴** — 8칸 아이콘 그리드 (위임목사·예배안내·주일설교·찬양·주보·행사사진·헌금·오시는길)
3. **예배 안내 + 오늘의 말씀** — 2단. 예배시간은 `church_info`, 말씀은 `daily_verse_for` RPC
4. **최근 설교** — `sermons` 최신 3건 카드
5. **교회 소식** — `notices`. RLS상 로그인 사용자만 조회 가능 → 비로그인은 빈 배열이 와서
   섹션 자체가 숨겨진다(에러 아님)
6. **처음 오셨나요 CTA 밴드**
7. **전체 메뉴** — 기존 사이트맵 그리드를 재배치

### 헤더 / 모바일 내비 / 푸터

- **`Header.tsx`** — 상단 유틸리티 바(예배시간 + 바로가기) + 스티키 메인 바.
  드롭다운에 밑줄 인디케이터와 영문 라벨(`labelEn`) 추가. `church_info`를 읽어야 해서
  async 서버 컴포넌트로 전환.
- **`MobileNav.tsx`** (신규) — **모바일 내비게이션이 아예 없던 상태였다.**
  우측 드로어, 배경 스크롤 잠금, ESC 닫기, 섹션별 목록.
- **`Footer.tsx`** — 4줄짜리 회색 바 → 교회 정보(주소/전화/이메일/예배시간) + 전체 사이트맵
  딥그린 푸터. `church_info` 조회를 위해 async 서버 컴포넌트로 전환.

### 신규 공용 모듈

| 파일 | 역할 |

## 4. 작업 중 발견해서 고친 기존 버그

1. **다크모드에서 글씨가 안 보였다.** `globals.css`에 `prefers-color-scheme: dark` 블록이
   있어서 배경만 `#0a0a0a`로 바뀌는데, 모든 페이지가 `text-gray-900`을 쓰고 있었다.
   교회 사이트에 다크모드가 필요하지 않다고 보고 `color-scheme: light`로 고정했다.
2. **예배 시간 하드코딩.** 헤더 상단바에 "오전 10:00 / 오후 7:30"을 박아뒀는데
   DB 실제 값은 "11:00 AM / 07:30 PM"이었다. 같은 페이지 안에서 값이 어긋나는 상태.
   헤더·푸터·홈 모두 `church_info` 단일 소스에서 읽도록 수정하고, 값이 없으면 그 줄을
   렌더링하지 않게 했다.
3. `about/worship`에서 `address`와 `address_en`이 DB에 같은 영문 주소로 들어 있어
   같은 줄이 두 번 나오던 문제 → 두 값이 다를 때만 영문을 추가 표시.

## 5. 검증

- `npm run build` 통과 (27개 라우트).
- `npx eslint src` — 남은 문제는 **이번 작업 이전부터 있던** `src/lib/useIsStandalone.ts`의
  `react-hooks/set-state-in-effect` 에러 1건과, 기존 코드 관례를 따른 `<img>` 경고 2건뿐.
  - `MobileNav`도 처음엔 `usePathname` effect로 드로어를 닫아서 같은 에러가 났는데,
    모든 `Link`의 `onClick`에서 직접 닫도록 바꿔 해결했다.
- dev 서버를 띄우고 렌더링된 HTML에서 텍스트만 추출해 **실제 Supabase 데이터가 모두
  들어오는지 확인**했다 — 예배시간 11:00 AM / 07:30 PM, 주소, 오늘의 말씀(벧전 5:7),
  설교 3건(류성춘 목사), 푸터 이메일까지 정상.

## 6. 남은 것 / 참고

- **히어로 오프닝 영상**이 아직 CSS 그라데이션이다. `page.tsx`에 주석으로 자리를 표시해
  뒀고, `<video className="absolute inset-0 object-cover">`를 넣으면 기존 오버레이가
  그대로 가독성을 잡아준다.
- **설교 썸네일** — 현재 등록된 설교는 `video_url`이 없고 PDF `file_url`만 있어서
  십자가 아이콘 폴백으로 나온다. 유튜브 URL이 들어오면 `youtubeThumbnail()`이 자동으로
  썸네일을 만든다.
- **`PageHero` 미적용 페이지** — `daily-verse`, `about/worship` 외 나머지 페이지들은
  아직 예전 스타일이다. `<PageHero title="..." href="..." />`만 붙이면 되는 수준.
- **브랜드 색** — joych의 딥그린을 그대로 썼다. STLC 고유 색으로 갈지는 결정 필요.
- `src/lib/useIsStandalone.ts`의 린트 에러는 이번 범위 밖이라 손대지 않았다.
